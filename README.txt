MyLocalMarket product photos
============================

Put one photo per product in this folder. The website finds each photo by its
file name. If a photo is missing, the product simply shows its emoji instead,
so you can add photos a few at a time.

PHOTO SPECS
-----------
- Shape:  landscape 4:3 (for example 600 x 450 pixels). Other shapes still work,
          but they are cropped to fit the card.
- Size:   under about 100 KB each (phone photos are often 3-5 MB, which would
          make the shop page slow). Free tools to shrink and crop: squoosh.app,
          photopea.com, or your phone's photo editor.
- Format: .jpg (the default). If you use .png or .webp for all photos, change
          imageExtension at the top of script.js.
- Names:  lowercase letters, numbers and hyphens only, exactly as listed below.

PRODUCTS YOU ADD IN THE SHOP OWNER DASHBOARD
--------------------------------------------
Copy the photo into this folder, then type its file name in the "Photo file name"
box (for example sweet-potatoes.jpg). If you leave the box blank, the site looks
for <product-name>.jpg, so "Sweet Potatoes" looks for sweet-potatoes.jpg.

WHERE TO GET PHOTOS
-------------------
- Best: take them yourself at a market or shop. No licence worries.
- Free stock sites (Unsplash, Pexels, Pixabay): check the licence on each photo.
- Wikimedia Commons: each image has its own licence and often needs credit.
- Do not copy images from random websites or Google Images.
If your lecturer expects sources, keep a short list of where each photo came from.
